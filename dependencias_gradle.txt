--- Solo si al compilar sale "Duplicate files copied in APK META-INF/..." ---
Dentro de android { } agrega:
    packagingOptions {
        exclude 'META-INF/LICENSE.md'
        exclude 'META-INF/NOTICE.md'
        exclude 'META-INF/LICENSE'
        exclude 'META-INF/NOTICE'
    }
(en Kotlin DSL: packaging { resources { excludes += setOf("META-INF/LICENSE.md","META-INF/NOTICE.md","META-INF/LICENSE","META-INF/NOTICE") } })

    maven { url 'https://jitpack.io' }
